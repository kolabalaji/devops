# What is DevOps?

## Simple Explanation

DevOps means **Development** + **Operations** working together as one team, instead of two separate teams.

In the old way:
- Developers write code and throw it "over the wall"
- Operations team receives it and has to make it run
- If something breaks, both teams blame each other

In the DevOps way:
- Developers and Operations work together from day one
- They share the same goal: deliver good software, fast and safely
- They use automation to reduce manual work and human errors

## Core Idea (One Line)

> DevOps is a culture and a set of practices that helps teams build, test, and release software faster, more reliably, and with fewer mistakes.

## Key Pillars

1. **Collaboration** – Dev and Ops talk to each other, not just hand off work
2. **Automation** – Let tools do repetitive tasks (build, test, deploy, patch)
3. **Continuous Integration (CI)** – Merge code changes frequently and test automatically
4. **Continuous Delivery/Deployment (CD)** – Ship code to production quickly and safely
5. **Monitoring & Feedback** – Watch systems live, learn fast, fix fast

## Common DevOps Tools

| Purpose | Tools |
|---|---|
| Version Control | Git, GitHub, GitLab |
| CI/CD | Jenkins, GitHub Actions, GoCD, Bamboo |
| Configuration Management | Ansible, Puppet, Chef |
| Infrastructure as Code | Terraform |
| Containers | Docker, Kubernetes |
| Monitoring | Prometheus, Grafana, Nagios |

## Daily Affirmations for a DevOps Mindset

- 🟢 *"I automate today what I don't want to repeat tomorrow."*
- 🟢 *"I build systems that fail safely and recover quickly."*
- 🟢 *"I collaborate, I don't isolate."*
- 🟢 *"Every deployment makes me faster and more confident, not more afraid."*
- 🟢 *"I measure, I monitor, I improve — every single day."*
- 🟢 *"Small, frequent changes are safer than big, risky ones."*
- 🟢 *"I own the code from commit to production."*

## In One Sentence

**DevOps = People + Process + Automation, working together to deliver software faster and more reliably.**
